

# TinyTextExtract

TinyTextExtract is a simple Optical Character Recognition (OCR) system designed to process images containing text in a 5x7 grid format. It features a user-friendly Flask web application that allows image uploads and displays recognized text results.

## Features

- **5x7 Grid Input:** Users can interact with a 5x7 grid to input or visualize their text.
- **OCR Processing:** Upload images and receive recognized text using the built-in OCR engine.
- **Web Interface:** Clean and simple frontend built with Flask, HTML, and CSS.
- **Result Display:** Recognized text is displayed directly on the web page after processing.

## Installation

### Prerequisites

- Python 3.8 or higher
- pip (Python package manager)

### Clone the Repository

```bash
git clone https://github.com/ishokuP/TinyTextExtract.git
cd TinyTextExtract
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```

The application will be available at `http://127.0.0.1:5000/` by default.

## Usage

1. Open your browser and go to the local address shown after running the app.
2. Upload your image with text in a 5x7 grid format.
3. View the recognized text on the results page.
